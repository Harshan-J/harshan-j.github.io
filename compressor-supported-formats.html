Compressor: Image & PDF

Updated 23 Sep 2026  ·  App version 17.0  ·  Package com.harshanaj.compressor

In short: Compressor reads standard photo formats (JPEG, PNG, WebP, GIF, BMP, HEIC), TIFF, over 20 camera RAW formats from every major manufacturer, and PDF documents — all processed and decoded entirely on your device, including large 50MP+ RAW and TIFF files.

01 Standard image formats

Decoded natively via Android's built-in image codecs, in Compress Images, Crop, Resize, and Images to PDF:

.jpg / .jpeg .png .webp .gif .bmp .heic / .heif

02 TIFF

Android has no built-in TIFF codec, so Compressor decodes it directly with its own reader:

.tif .tiff

Includes real thumbnail previews and safe handling of very large TIFF files (tested up to 50MP+) without running out of memory.

04 PDF documents

.pdf

Accepted by every PDF tool — Compress, Merge, Split, and PDF to Images.

05 How files are picked

Compress Images, Crop, Resize, and Images to PDF all share a single file picker (Android's Storage Access Framework document picker) that surfaces every format above in one place — rather than the system Photo Picker, whose format list is fixed by Google and can never show TIFF or RAW files.

06 Large file handling

TIFF and RAW files are read in two cheap steps — dimensions first, then a downsampled decode — so a 50+ megapixel file doesn't require decoding at full resolution just to preview or compress it. This keeps memory use bounded regardless of source file size.

07 Not currently supported

SVG and PSD files can be selected in the picker but currently fail to decode with a clear error message — no crash, no partial output.
